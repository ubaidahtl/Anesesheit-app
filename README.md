# مدرستي — نواة مبسطة جديدة

إصدار تأسيسي مستقل لإثبات مسار: إضافة أشخاص → إنشاء نشاط → اختيار الحاضرين وتعيين الحالة → حفظ سجل النشاط وحضوره معًا → مراجعة السجل لاحقًا.

## التخزين
- IndexedDB قاعدة مستقلة `madrasti-core-v1` (لا تستخدم قاعدة التجارب القديمة).
- مخزنان فقط: `people`, `activities`.
- سجل النشاط يحمل `attendance` كمصفوفة داخله؛ يتم حفظ النشاط وكل حالات الحضور في `put` واحد، لتفادي الحفظ الجزئي بين جدول النشاط وجدول الحضور.
- البيانات محلية في المتصفح ولا يوجد إرسال سحابي.

## نشر
ارفع محتويات المجلد إلى استضافة HTTPS. افتح الرابط من Safari. يمكن إضافة الصفحة للشاشة الرئيسية.

## حدود هذه النسخة
نسخة أساس للتحقق من تدفق العمل، وليست بعد النظام النهائي متعدد المدارس/المجموعات أو التقارير الرسمية. الحذف في هذه النسخة حذف نهائي. تصدير/استيراد النسخ الاحتياطية وإدارة المدارس والأدوار ضمن مراحل لاحقة.

## اختبار يدوي مطلوب
1. أضف شخصين.
2. أنشئ نشاطًا وحدد الحالات.
3. احفظ، انتقل إلى الأنشطة المحفوظة وافتح تفاصيل الحضور.
4. أغلق التطبيق وافتحه وتحقق من بقاء السجل.
5. احذف نشاطًا تجريبيًا وتأكد من اختفائه.
